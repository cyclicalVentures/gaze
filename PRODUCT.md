# Gaze
A browser-based PLY and USDZ viewer for desktop and iOS, with camera-based eye navigation, immersive viewing on capable devices, and a second tab for recording and reviewing gaze sessions.

The primary task is to open a local model, inspect it with mouse/touch, and optionally use camera tracking. User-supplied demo: /tmp/USDZ-test.usdz (Scaniverse textured binary USD).

Visual reference: ~/stridemind. Inherit Space Grotesk, deep violet surfaces, teal signals, coral primary actions, restrained angular details.

Confirmed user direction: reconstruct the view from the head/eye position so the screen looks like a box with depth. Use fixed-screen off-axis projection; eye rotation must not orbit the scene. Start with a cube, retain PLY/USDZ import and bundled Scaniverse demo. Research current papers and GitHub implementations. Webcam estimates are approximate. No native continuous eye-gaze API is assumed. Browser support is detected. iOS has touch and Quick Look; the clarified window effect does not require WebXR or a headset. Local model and camera processing stays in the browser. No account is needed. User-chosen tuning settings and, as requested on 7 September 2026, multi-distance gaze calibration can be saved in local browser storage. Gaze saves are associated with the actual webcam device ID. Camera images are never persisted.

Eye orientation follows the JEOresearch Webcam3DTracker approach: calibrated head-local eye spheres plus iris direction. Guided calibration sweeps one setting at a time; the user freezes their preferred value, reviews, and saves. Preserve the fixed screen plane.

The saved Grow when closer preference changes virtual Z motion while preserving measured distance. After the user reported reverse zoom and clarified that the cube should grow on approach, this is now enabled by default; physical window scaling remains selectable. Show the measured screen-distance estimate separately from the tuned virtual viewpoint so users can diagnose the reported reverse-zoom sensation.

The default head estimator now fits a frozen neutral face shape using WebEyeTrack-style radial refinement and robust reprojection. Keep the original nose-scale estimator selectable for comparison. A protected-focus gaze calibration collects nine known positions and validates five separate positions at each of three viewing distances before user application. Report actual CSS-pixel errors, reject poor fits, and preserve the previous mapping on cancel. Save & use stores the three gaze maps, sparse neutral face reference, physical measurements and accuracy summaries locally for the selected webcam. Raw frames and fixation samples remain transient. Compatible saves restore after the user enables that webcam; camera/screen mismatches block reuse. Provide per-camera deletion. Keep this accuracy calibration distinct from subjective depth-effect tuning.

Hand manipulation uses the current webcam, with optional MediaPipe hand detection alongside eye tracking. One thumb/index pinch and drag rotates the model; two pinches scale and twist. Releasing holds the transform. Open hands arm a new grab, with a short pinch dwell, hysteresis, continuity checks and loss release. Pause hand input during calibration, tuning and model loading. Keep manual model controls and a reset. Hands transform the model, never the fixed screen projection. Hand landmarks and gestures are transient and never saved.

The Gaze recorder tab captures approximate webcam gaze for later playback and dwell-time analysis. On capable desktop browsers, calibrate the entire game monitor in native fullscreen and keep the webcam, monitor and playing position consistent. Page scope is available for desktop and iOS while the page remains in front; it does not map gaze across other apps. Recorder calibration uses the existing three-distance, nine-target and five-check procedure, with measured CSS-pixel errors. Save profiles locally per actual webcam and coordinate scope, separately from the viewer's calibration space; restore only compatible profiles and provide deletion.

Record gaze alone or attach optional entire-screen video with no audio. Webcam images are never recorded. Gaze sessions, five-second checkpoints and screen-video chunks stay in this browser's IndexedDB, with session history, recovered-session notices, review and deletion. If local saving is unavailable, gaze-only sessions remain available in memory for immediate export. Playback supports a selected time range, gaze cursor and trail, dwell heatmap, region totals and separate on-screen, off-screen and unobserved time. Export session JSON, gaze CSV, the visible map as PNG and any recorded screen video. Each session stops at two hours or when screen video reaches the 512 MB limit. Browser suspension can interrupt sampling and saving; page-scope recording stops when backgrounded. Preserve gaps in playback and analysis, and never promise continuous game tracking through a hidden or minimized browser.
