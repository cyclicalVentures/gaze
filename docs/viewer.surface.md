# Viewer
Mode: Operate / Experience. Open immediately with the cube in a real off-axis 3D box. The supplied model is selectable. Orbit is a separate manual mode; Window uses head-coupled perspective. Camera setup uses neutral-pose calibration and clear cancel. Full view retains an exit. Errors preserve the last loaded model and permit retry. Tracking turns off when backgrounded. Model metadata comes from loaded geometry.

Guided calibration temporarily occupies the inspector while the model remains visible. On mobile, the viewport and scrollable calibration controls share the screen. One parameter varies at a time with an explicit choose/keep transition, pause, precise adjustment, back, recovery and cancel. A fixation target counts down before locking eye spheres.

Known-target gaze calibration uses a full-window native dialog to keep fixation targets stable and other controls out of focus. Collect nine targets, then five held-out checks at normal, near and far distances, with an 800ms settling interval per fixation. Show live distance guidance, require steady positioning before each set, and reset a fixation on distance drift. Provide pause, cancellation, retry, tracking-loss feedback, measured error and explicit application. Results show error for each distance and a selectable target-versus-estimate plot with textual error equivalents. Save & use persists the webcam-specific reference and maps; expose camera selection, saved-profile status, compatibility explanations and deletion. Session invalidation must block stale application. The existing camera video stays mounted throughout.
