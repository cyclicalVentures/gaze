# Gaze visual system
Inherit Stridemind's visual authority: Space Grotesk Variable, #0d0a1f base, #120e2a panels, #f4f1fb text, #b7afd6 secondary text, #2fd6c4 teal, #9b6bff violet, #ff5c56 coral.

The viewer is the surface. A slim header, large 3D viewport, and compact right inspector expose import, tracking, and presentation. Controls remain subordinate to the model. Fine rules organize sections; avoid repeated cards. On phones the model stays first and the inspector follows below. Compact angular logo, small square utility controls, clear visible focus rings. No decorative imagery; the actual model provides the visual content.
